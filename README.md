# Expense Tracker

A web-based Expense Tracker built using Python and Flask.

## Current Features

- Add expenses
- Display expenses
- Edit expenses
- Delete expenses
- Search expenses
- Sort expenses
- Calculate total expenses

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## Work in Progress

The following features are still being developed:

- User registration
- User login
- User authentication
- Additional improvements to the user interface
